runtraj.output.Output.failures#

Output.failures(kind, variant, release_ids=None, realization=None)[source]#

Return {release_id: record} for the releases with a failure record of kind.

With release_ids, only their date folders are listed. The records found are read in a few threads; one a worker removed meanwhile, as it does when the release’s result is written, is left out.

Return type:

dict[str, dict[str, Any]]

Parameters:

  • kind (Kind)

  • variant (Variant)

  • release_ids (Iterable[str] | None)

  • realization (int | None)
