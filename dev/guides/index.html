User Guide#

Each page covers one task, in the order you meet them. If you are new to runtraj, start with Your First Run, and look up a word in the Glossary.

Setting up a project

  • Projects And Variants: the project folder, config.yaml, and variants; how reruns and changed settings work

  • Releases: releases, the times and places particles start from (a point, a vertical column, or many points at once)

  • Meteorology: use your own ARL files or download them from NOAA

  • Choosing Settings: how long to run, how many particles, random numbers, and what HYSPLIT chooses for you

Running

  • Running: run on your computer, and the commands

  • Checking A Run: find problems before a run, see where each simulation stands, and find out why one failed

  • On An HPC Cluster (Slurm): run thousands of simulations on an HPC cluster

  • In Containers (Kubernetes): run with Kubernetes or another scheduler

  • Setting Up Kubernetes: the image, a cluster and a bucket for Kubernetes, on your computer or on Google Cloud

Results

  • The Output Directory: what is in the output directory, and putting it on an object store

  • Reading And Plotting Particles: read and plot the particles of one simulation or many, and open them in DuckDB, R, or CF trajectory tools

  • Concentration Grids: HYSPLIT’s concentration grids, of pollutants you release, in place of particles

  • Trajectories: HYSPLIT’s single trajectories, one from each release location, with no turbulence

HYSPLIT

  • runtraj For HYSPLIT Users: HYSPLIT’s starting points, settings and particle output in runtraj, a single trajectory, and many runs as a project

  • Your Own HYSPLIT Build And Data Tables: run another HYSPLIT build, or your own land-use and terrain tables
