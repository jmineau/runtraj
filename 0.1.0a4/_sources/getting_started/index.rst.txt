Getting Started
===============

New to runtraj? Read these in order.

1. :doc:`installation` installs the package and says where to get HYSPLIT.
2. :doc:`quickstart` runs one release, then the same release as a project.

Then go on to the :doc:`../guides/index`, starting with
:doc:`../guides/projects`. If you have run HYSPLIT on its own,
:doc:`../guides/hysplit_users` maps its ``CONTROL`` and ``SETUP.CFG`` to
runtraj's settings.

The :doc:`glossary` says what runtraj's words mean, such as release,
variant, and settings folder.
